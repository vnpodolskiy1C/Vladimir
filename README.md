# Сервис объектов: стартовое состояние

Расширение `СчетаМагазина` после доработки сервиса счетов. HTTP-сервис уже переведён
на корень `objects`, маршруты из ТЗ заведены, обработчики пока отвечают `501`.
Логика описания по метаданным, преобразования значений, поиска и чтения счёта — в общих модулях,
а как сервис записывал счёт — в его спецификации и плане.

| Путь | Что это |
| --- | --- |
| `СчетаМагазина.cfe` | расширение для загрузки в базу |
| `src/extensions/СчетаМагазина/` | исходники расширения (XML, формат Hierarchical) |
| `src/tests/objects.http` | запросы REST Client, по одному на маршрут |
| `src/tests/.env` | адрес, авторизация и идентификаторы демо-данных для запросов |
| `docs/superpowers/` | спецификация и план сервиса счетов — образец процесса |

Начало работы: загрузить `СчетаМагазина.cfe` в базу из `1Cv8_demo.dt`, опубликовать базу
на веб-сервере, поправить в `.env` адрес и авторизацию и выполнить любой запрос из
`objects.http` — ответ `501` значит, что всё подключено.
