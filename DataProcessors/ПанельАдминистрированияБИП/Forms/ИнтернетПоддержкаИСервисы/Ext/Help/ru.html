В данной панели выполняется настройка работы с сервисами Интернет-поддержки пользователей, просмотр информации о поддержке программного продукта, доступных обновлениях и др.

Настройки Интернет-поддержки

  • Логин - сохраненный в программе логин, используемый для входа в систему Интернет-поддержки пользователей. Для входа в систему Интернет-поддержки пользователей используется тот же логин и пароль, что и на сайтах portal.1c.ru и portal.1c.eu. Если у вас еще нет логина и пароля, то выполните регистрацию самостоятельно или обратитесь за помощью к партнеру фирмы "1С", с которым у Вас заключен договор ИТС.
  • Подключить - ввести логин и пароль для подключения ко всем сервисам Интернет-поддержки. Введенные логин и пароль будут сохранены в программе.
  • Отключить - удалить из программы логин и пароль для подключения к сервисам Интернет-поддержки.
  • Сообщение в службу технической поддержки - перейти на Портал 1С:ИТС для отправки сообщения в службу технической поддержки. К данным сообщения будет автоматически добавлена техническая информация о программе.
  • Техническая информация - сохранение файла с технической информацией, которую могут запросить в службе технической поддержки.
  • Информационно-техническое сопровождение (1С:ИТС) - открывает страницу портала информационного технического сопровождения its.1c.ru или its.1c.eu.
  • Монитор Портала 1С:ИТС - информация о поддержке программного продукта, версии программы и др.

Классификаторы и курсы валют

  • Обновление классификаторов - переход к загрузке и обновлению классификаторов банков, валют, стран мира, производственных календарей, а также других классификаторов. Обновление можно выполнить через Интернет или из файла на компьютере.
  • Автоматическое обновление классификаторов - c помощью переключателя можно выбрать правило автоматического обновления классификатора:
    • Отключена - автоматическое обновление классификаторов не будет выполняться.
    • По расписанию через Интернет - автоматическое обновление классификаторов будут загружаться из сервиса на Портале 1С:ИТС.
    • По расписанию из файла - автоматическое обновление классификаторов будут загружаться из указанного файла.
  • Расписание - время запуска автоматического обновления классификаторов.
  • Загрузка адресного классификатора - загрузка адресного классификатора с портала 1С:ИТС или из папки на диске.
  • Очистка - удаление загруженных адресных сведений по выбранным, неиспользуемым регионам для уменьшения размера базы.
  • Подбирать и проверять адреса через Интернет, который не загружены в приложение - с помощью флажка можно включить/отключить доступ к веб-сервису адресов.
  • Загрузка курсов валют - загрузка курсов валют из сети Интернет.

Новости

  • Включить работу с новостями - включение/отключение подсистемы Новости.
  • Управление новостями - управление настройками новостей, а также ручное обновление классификаторов и списка новостей.

Обновление версии программы

  • Обновление программы - открывает помощник поиска и установки обновлений.
  • Описание изменений программы - открывает список изменений в установленной версии программы.
  • Автоматическая проверка обновлений - настройка правила автоматической проверки наличия доступных обновлений:
    • Отключена - проверка доступных обновлений не будет выполняться.
    • При запуске программы - проверка доступных обновлений будет выполняться каждый раз при запуске программы.
    • По заданному расписанию - проверка доступных обновлений будет выполняться по заданному расписанию.
  • Информировать о выходе - настройка правила оповещения о выходе новой версии программы:
    • актуальных версий программы - будет отображаться уведомление о выходе любой новой версии программы.
    • версий длительной поддержки - будет отображаться уведомление о выходе новой сборки текущей версии в период срока поддержки и о выходе новой версии после окончания срока поддержки у текущей версии.
  • Загружать и устанавливать исправления (патчи) автоматически - включение/отключение признака автоматической загрузки и установки опубликованных разработчиками программы исправлений (патчей). После включения настройки можно будет настроить расписания автоматической загрузки и установки исправлений (патчей).
  • Результаты обновления и дополнительная обработка данных - сведения о ходе обновления версии программы, отложенное выполнение дополнительных процедур обработки данных.
  • Детализировать ход обновления в журнале регистрации - при включенном флажке в журнал регистрации записываются выполняемые обработчики обновления с указанием времени выполнения.

Проверка контрагентов

Центр мониторинга

В подразделе представлены настройки сбора, анализа и хранения технологической информации, обезличенной статистики использования конфигурации. Отчеты об использовании программы, автоматически переданные разработчикам, помогут им определить, над чем следует поработать в первую очередь. Собранные сведения являются обезличенными и содержат только статистические показатели. Подготовка и отправка отчетов не замедлит работу программы.

С помощью переключателя выберите:

  • Разрешить автоматическую отправку сведений об использовании программы в фирму "1С" - выбрано по умолчанию, рекомендуется.
    • Настройки центра мониторинга - перейдите по ссылке, для того чтобы разрешить отправку отчетов об ошибках, а также указать, спрашивать ли каждый раз перед отправкой данных.
    • Сообщить о проблемах производительности - открывает помощник решения проблемы производительности.
  • Разрешить отправку сведений стороннему разработчику - в этом случае необходимо заполнить Адрес сервиса.
  • Запретить отправку сведений - не рекомендуется, т.к. статистика необходима разработчикам для анализа работы программы, при этом передача статистики не замедляет ее работу.
