Помощник предназначен для автоматического получения обновлений программы из сервиса обновлений программ и установки полученных обновлений. Помощник выполняет последовательность шагов, которые позволяют выбрать вариант обновления, получить и установить файлы обновлений платформы и конфигурации, а также при необходимости установить исправления (патчи).

Общий порядок работы

Работа с помощником обновления программы состоит из следующих основных шагов:

  • выбор варианта обновления;
  • просмотр информации о доступном обновлении;
  • подключение к Порталу 1С:ИТС - ввод логина и пароля пользователя Портала 1С:ИТС;
  • получение файлов обновлений и исправлений (патчей), установка новой версии платформы 1С:Предприятие (при необходимости);
  • установка обновления конфигурации;
  • установка исправлений (патчей) конфигурации.

Шаг "Выбор варианта обновления"

На данном шаге отображается список всех версий конфигурации, доступных для установки, и информация о текущей версии. Этот шаг отображается в случаях, когда:

  • текущая версия программы находится на длительной поддержке;
  • доступно более одной версии программы для обновления.

Верхняя часть экрана показывает полный номер текущей версии конфигурации и ниже перечислены доступные варианты обновления:

  • пункт обновления текущей версии (включая информацию о сроке длительной поддержки и наличии обновлений);
  • варианты перехода на более новые версии с длительной поддержкой (при наличии);
  • вариант обновления до последней (актуальной) версии конфигурации.

Параметр Информировать о выходе задает правило уведомления о доступных обновлениях:

  • актуальных версий - уведомлять о выходе любой новой версии конфигурации;
  • версий длительной поддержки - уведомлять о выходе новых сборок текущей версии в период ее поддержки и о выходе новых версий после окончания срока поддержки текущей версии.

Если у пользователя уже имеется файл обновления и требуется установить обновление из файла, следует перейти по гиперссылке установить обновление конфигурации из файла, чтобы открыть помощник установки обновления из файла (см. подсистему "Обновление конфигурации" библиотеки стандартных подсистем).

Шаг "Просмотр информации о доступном обновлении"

На этом шаге отображается информация о выбранном варианте обновления, включая размер пакета обновления и (при выборе конкретной версии) номер версии и срок ее длительной поддержки.

Обновление конфигурации

Содержит информацию о доступном обновлении конфигурации:

  • номер версии конфигурации, которая будет установлена;
  • размер обновления, загружаемого на компьютер;
  • новое в версии - ссылка на описание изменений в новой версии;
  • номер текущей версии конфигурации для сравнения.

Обновление конфигурации может быть:

  • Обязательным - выбор компоненты обновления конфигурации фиксирован и его нельзя снять.
  • Рекомендуемым - флаг установлен по умолчанию, но его можно снять.
  • Недоступным - при выборе варианта обновления текущей версии, по которой закончилась или отсутствует длительная поддержка, компонент обновления конфигурации может не отображаться.

Исправления (патчи)

Содержит информацию о доступных исправлениях ошибок конфигурации (патчах). Для выбранной версии (новой или текущей) доступен список исправлений и возможность выбрать, какие из них устанавливать.

Загружать и устанавливать исправления (патчи) автоматически - при включении этой настройки исправления будут загружаться и устанавливаться регламентным заданием по расписанию (в тихом режиме). Частота загрузки и установки исправлений (патчей) определяется выбранным Расписанием.

Обновление платформы 1С:Предприятие

Содержит информацию о доступном обновлении платформы 1С:Предприятие:

  • номер версии платформы 1С:Предприятие;
  • размер дистрибутива, который будет загружен на компьютер;
  • информация об особенностях перехода на новую версию платформы.

Если доступна новая версия конфигурации, помощник выбирает версию платформы, необходимую для работы с новой версией; иначе - версию для текущей конфигурации.

Параметры установки платформы

Параметры определяют поведение установки дистрибутива платформы:

  • Режим установки платформы:
    • Установить с настройками по умолчанию - установка в тихом режиме без отображения мастера установки.
    • Установить с ручными настройками - интерактивный режим: откроется программа установки платформы, где доступны все параметры установки. Следуйте инструкциям установщика, после завершения установка автоматически продолжится в помощнике.
  • Каталог хранения дистрибутивов платформы:
    • Если установлен флаг Сохранять полученные дистрибутивы платформы в каталог, дистрибутивы будут сохраняться в подкаталогах с именем версии, если флаг не установлен - сохраняется только последний полученный дистрибутив.
    • Рекомендуется копировать полученные дистрибутивы в локальный или сетевой каталог, если планируется последующая установка платформы на других компьютерах.

В операционных системах Linux и macOS автоматическая установка платформы недоступна - скачайте дистрибутив с ресурса releases.1c.ru и выполните установку вручную согласно инструкции. В клиент-серверном режиме автоматическая установка платформы также недоступна - необходимо загрузить дистрибутив по ссылке "Загрузить дистрибутив" и установить вручную.

Шаг "Подключение к Порталу 1С:ИТС"

Получение обновлений доступно только зарегистрированным пользователям Портала 1С:ИТС. Введите логин и пароль пользователя Портала 1С:ИТС. При успешном подключении данные будут сохранены в программе для последующего использования.

  • Логин - логин пользователя Портала 1С:ИТС.
  • Пароль - пароль пользователя Портала 1С:ИТС.

Переход к шагу подключения происходит в случаях, когда:

  • не подключена Интернет-поддержка (логин/пароль не введены);
  • логин/пароль, сохраненные в программе, некорректны;
  • пользователь с указанным логином не имеет доступа к получению обновлений согласно условиям поддержки (не оформлена подписка или нет договора сопровождения).

Шаг "Получение файлов обновлений"

После выбора версии и подключения к Порталу 1С:ИТС начинается загрузка файлов обновлений и исправлений. На этом шаге отображается прогресс получения файлов.

Также на данном шаге выполняется установка новой версии платформы в соответствии с выбранными настройками. Если платформа 1С:Предприятие устанавливается с ручными настройками, открывается окно программы установки 1С:Предприятие. Следуйте инструкциям программы установки в открывшемся окне. После завершения установки 1С:Предприятие выполнение будет автоматически продолжено.

После успешного получения файлов и завершения установки платформы происходит переход к одному из шагов:

  • Завершение установки платформы 1С:Предприятие - если была обновлена только платформа.
  • Установка обновления конфигурации - если было получено обновление конфигурации.

Проблемы при получении файлов обновлений

При возникновении проблем с получением обновлений отображается сообщение с описанием проблемы. Записи о произведенных операциях и возникших ошибках в ходе обновления записываются в Журнал регистрации (событие "Получение обновлений программы").

Завершение установки платформы 1С:Предприятие

После успешной установки новой версии платформы отображается информация:

  • номер установленной версии платформы;
  • каталог, в который был сохранен полученный дистрибутив;
  • флажок "Автоматически создать резервную копию и открыть программу на новой версии платформы" - при установленном флажке при нажатии "Готово" будет выполнено создание резервной копии информационной базы, после чего программа автоматически откроется на новой версии платформы.

Перед открытием программы на новой платформе рекомендуется:

  • завершить работу всех активных пользователей;
  • завершить текущий сеанс работы с программой;
  • установить новую версию платформы на компьютеры других пользователей;
  • открыть программу на новой версии платформы.

Установка обновления конфигурации

После получения обновления конфигурации помощник предлагает его установить. Если одновременно была обновлена платформа, после успешной установки обновления конфигурации программа будет открыта на новой версии платформы.

Поведение шага установки полностью соответствует описанию в подсистеме "Обновление конфигурации" библиотеки стандартных подсистем. Подробную инструкцию по установке обновлений см. в разделе "Установка обновлений" справочной информации помощника установки обновлений.
