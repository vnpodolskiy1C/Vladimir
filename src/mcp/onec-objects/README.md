# onec-objects

MCP-сервер проекта: даёт агенту инструменты для работы с объектами 1С через
HTTP-сервис объектов и ресурс «Типы объектов 1С» — список типов, который
приложение может подложить в контекст. Лежит в `src/mcp/onec-objects`.

Инструменты регистров сведений (`describe_register`, `read_register_slice`,
`read_register_history`, `write_register_record`) объявлены, но пока отвечают
заглушкой и в сервис не ходят.

## Переменные окружения

| Переменная | Что это |
| --- | --- |
| `OBJECT_SERVICE_URL` | адрес сервиса объектов, до `/hs/objects` включительно |
| `OBJECT_SERVICE_USER` | пользователь 1С |
| `OBJECT_SERVICE_PASSWORD` | пароль пользователя 1С; пустой можно не задавать |

Адреса, пользователя и пароля нет ни в коде, ни в записи подключения: их задаёт
окружение, в котором агент запускает сервер. Если адрес или пользователь не заданы,
сервер пишет причину в stderr, завершается с кодом 1 и сессию инструментов не открывает.

## Установка и сборка

Команды выполняются в каталоге `src/mcp/onec-objects`:

```bash
npm ci
npm run build
```

Сборка кладёт результат в `dist/`; зависимости и `dist/` в git не входят.

## Проверка

```bash
npm test
```

## Подключение

Агент запускает собранный сервер командой `node src/mcp/onec-objects/dist/index.js`
из корня проекта. Перед первым подключением и после правок кода выполнить `npm ci`
и `npm run build`.
